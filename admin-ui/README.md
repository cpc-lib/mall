# admin-ui — 管理后台前端

管理后台单页应用（React 18 + Vite 5 + Ant Design 5），左侧导航 + 列表 + 抽屉详情布局，开发端口 `3002`，通过 CORS 直连后端 `http://localhost:8080`。

## 功能概览

- **订单管理**：多状态线筛选、详情抽屉、强制关单（幂等）、标记已付、渠道查单、支付单渠道尝试记录
- **订单发货**：待发货列表、模拟发货（运单号）
- **商品库存**：新增商品、库存调整（单个/批量）、上架/下架、库存操作日志与流水
- **批量库存维护**：Excel（.xlsx）导入 → Luckysheet 全屏编辑器核对 → 确认入库；失败行记录原因
- **退款受理**：受理/拒绝/退货签收/渠道重试/状态查询/差价退款
- **用户管理**：分页搜索、禁用启用、登录锁定查看、密码重置受理
- **账单对账**：微信交易账单 CSV 上传、批次/流水/差异查询、差异标记处理
- **支付配置**：渠道/应用管理（商户参数内联维护）、配置重载
- 双 Token 无感刷新（401 单飞刷新）

## 命令

```bash
npm install          # 安装依赖（Node.js 18+）
npm run dev          # 启动开发环境 → http://localhost:3002
npm run build        # 生产构建
npm run test:logic   # 逻辑单测（Token 单飞刷新）
```

## 后端接口地址

默认请求 `http://localhost:8080`，配置见 `src/utils/request.js` 的 baseURL。
