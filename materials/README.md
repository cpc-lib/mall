# materials 行动卡总览

本目录为 AI 编码协作流程行动卡集合，共 7 张卡片，覆盖**代码导览 → 测试 → 重构 → 结构梳理 → spec/issue 治理 → GitHub 协作 → 生成-验证-修正闭环**全流程。每张卡片结构一致（输入 → AI 动作 → 人审动作 → 完成标准 → 禁止事项 → 可复制 Prompt），可直接作为 AI 协作提示词使用。

## 使用顺序建议

**新接手项目**：01（架构梳理）→ 04（结构梳理）→ 05（spec/issue 盘点）

**准备改动**：05（问题分类 + spec 登记）→ 02（锁现状测试）→ 03（小步重构）→ 07（编码飞轮）→ 06（提交 PR 规范）

## 与项目文档的关系

- 本目录卡片为**通用流程模板**，可复用到任何项目。
- 项目级规则见根目录 [AGENTS.md](../AGENTS.md)（issue 分类、分支命名、spec 治理、DoD 等）。
- 具体规格账本见 [spec/](../spec/) 目录（planned / implemented / archived / governance 四态）。
- 当前项目的行为规格见 [CODE_INTRO.md](../CODE_INTRO.md)（代码导览）与 [README.md](../README.md)（项目总览）。
