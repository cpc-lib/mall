# payment-demo-react

这是从 Vue2 版本改写而来的 React 版本支付前端示例。

## 环境要求

建议使用 Node.js 18+。

## 安装依赖

```bash
npm install
```

## 启动开发环境

```bash
npm run dev
```

默认启动端口：`3000`。

## 打包

```bash
npm run build
```

## 后端接口地址

前端默认请求后端：

```text
http://localhost:8080
```

前端端口为 `3000`，后端默认接口地址为 `http://localhost:8080`，避免前后端端口冲突。

## 功能说明

- 课程列表
- 微信 Native 支付二维码
- 微信 V2 Native 支付二维码
- 支付宝电脑网站支付
- 订单列表
- 订单取消
- 退款申请
- 退款申请记录
- 微信账单下载
- 支付宝账单下载
